1. Transformasi Konten LMS Fleksibel

New Feature

Implementasi modul evaluasi akhir (Post Test). Ketika peserta mencapai ambang batas nilai kelulusan, sistem secara otomatis menerbitkan e-sertifikat resmi tanpa perlu approval manual admin satu per satu.

Integration

Mengintegrasikan sistem autentikasi tunggal (Single Sign-On) Kemnaker RI via Socialite OAuth. Peserta dan pegawai kementerian dapat login satu kali (SSO) dengan akun SIAPkerja tanpa perlu registrasi akun baru terpisah.

Hardening

Slide 04 / 07

Kondisi Sebelumnya (Legacy)

Terbatas & Monoton

  • Hanya Unggah File Lampiran: Materi hanya berupa file PDF/dokumen terpisah yang harus diunduh dulu oleh pengguna.
  • Tidak Ada Formula Matematis: Rumus perhitungan tenaga kerja (PUK, TPAK, TPT) harus dibuat dalam bentuk gambar pecah/buram.
  • Terputus dari Referensi Buku: Tidak ada keterkaitan dengan koleksi perpustakaan digital instansi.
  • Kurang Nyaman di HP/Mobile: File dokumen tidak responsif dan teks sulit dibaca di smartphone.
Kelemahan: Engagement peserta rendah & materi sulit dipahami

Kondisi Sekarang (Modernized)

Kaya Fitur, Interaktif, & Nyaman Dibaca

  • Fleksibilitas Editor Penuh: Administrator dapat menulis paragraf rata kanan-kiri (justify), menyusun daftar, dan format teks bebas.
  • Integrasi KaTeX Matematika Presisi: Rumus RTK Makro ($PUK, TPAK, TPT$) di-render tajam, indah, dan berbasis LaTeX standar ilmiah.
  • Hubungan Referensi & Koleksi Buku: Dilengkapi list dokumen unduhan dan buku perpustakaan digital langsung di bawah materi.
  • Reader Mode & Dark Mode: Dilengkapi tombol mode malam, ukuran font dinamis, dan navigasi ramah mobile.
Keunggulan: Pemahaman teori & formula ketenagakerjaan meningkat tajam
Database Seeder: Seluruh modul dummy kini telah di-update dengan materi resmi RTK Makro lengkap dengan rumus matematika KaTeX. CourseSectionSeeder Synced

Integrasi SSO SIAPkerja & Penambalan Celah Keamanan (Vulnerability Fix)

Slide 06 / 07

Integrasi SSO SIAPkerja Kemnaker

Socialite OAuth 2.0 Integration

Menghubungkan autentikasi pengguna ke ekosistem terpadu SIAPkerja Kementerian Ketenagakerjaan:

  • Single Sign-On (SSO): Peserta cukup login menggunakan akun SIAPkerja tanpa harus mengingat password baru.
  • Penyelarasan Akun Cerdas (Auto-Link): Mengaitkan email lokal dengan ID SIAPkerja secara aman tanpa membuat akun duplikat.
  • Manajemen Token: Menyimpan access token & refresh token untuk menjaga sesi autentikasi tetap valid.
Protokol: OAuth 2.0 Client-Server Terhubung & Aktif

Perbaikan Bug Keamanan (Security Fixes)

Vulnerability Elimination & Patching

Menutup berbagai potensi celah keamanan berdasarkan audit teknis aplikasi:

  • Sanitasi Rich Content (Anti-XSS): Filter tag berbahaya pada konten yang disimpan dari teks editor Quill.
  • Proteksi Hak Akses (Authorization Guard): Pengetatan middleware RBAC pada endpoint materi, evaluasi, dan data pengguna.
  • Validasi Upload Berkas: Pembatasan ekstensi dokumen (PDF, ZIP, DOCX) & validasi mime-type server-side.
Audit Status: Zero Critical Vulnerability Hardened
Perbaikan Minor Terkait: Fix jumping scrollbar saat submit formula KaTeX, penataan posisi tooltip menu Quill, & pembersihan layout padding desktop. Clean Code Standard
